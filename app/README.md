# আমাদের মসজিদ — Masjid Management Android App (APK Mod)

**নাম:** আমাদের মসজিদ (Amader Masjid) — Baitul Ma'mur Jame Mosque Management App
**বিবরণ:** রাধানগর পশ্চিমপাড়া বাইতুল মামুর জামে মসজিদ, রায়পুরা, নরসিংদীর জন্য বাংলা ভাষার মসজিদ ব্যবস্থাপনা অ্যাপ। একটি সিঙ্গেল-ফাইল HTML অ্যাপ Android WebView APK-তে এমবেড করা (apktool দিয়ে মডিফাই), ডেটা Firebase Firestore (প্রজেক্ট `masjid-9444c`) REST এ, অফলাইন-প্রথম (localStorage ক্যাশ + সিঙ্ক কিউ)।
**মালিক:** Abdullah Al-Mamun · **সর্বশেষ:** v33 (versionCode 49)

- আয়-ব্যয়, দাতা, কর্মচারী, উন্নয়ন তহবিল, নোটিশ (PDF), চ্যাট, প্রোফাইল, নোটিফিকেশন, অডিট লগ
- ভূমিকা: সুপার অ্যাডমিন / অ্যাডমিন / দর্শক; ডিভাইস অনুমোদন; যেকোনো ইউজার নেমে লগইন (ইমেইল/ফোন/নাম)
- সাধারণ অ্যাডমিনের আলাদা বেতন-ড্যাশবোর্ড; সদস্যের নিজের হিসাব
- স্বয়ংক্রিয় সাপ্তাহিক ব্যাকআপ, CSV, WhatsApp/SMS তাগাদা, অফলাইন বার্তা

## বিল্ড (apktool + uber-apk-signer)
`tools/mk.sh <html> <versionName> <versionCode>` → assets/index.html বসায়, versionCode/Name বদলায়, `apktool b`, META-INF সরিয়ে পুনরায় সই (একই ডিবাগ সার্টিফিকেট SHA256 1e08a903…5953, নাহলে আপডেট হবে না)।
নেটিভ কোড শুধু হাতে লেখা smali (d8/android.jar নেই)। JS↔নেটিভ ব্রিজ: `Android.sms/wa/exit/ready`।
